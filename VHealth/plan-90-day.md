# V-Health 90天增长计划

> 计划期：2026-11-12 至 2027-02-10，检查点延续到 2027-05 · 来源：[Grill 访谈](./interview-qa-zh.md) · 配套文件：[6个月 OKR](./okr-6-month.md)

**目标**：到2027年5月底，预约从每月约300次翻倍到**每月600次**，同时让说英语的本地新客户占比持续上升。每一项行动都有要达到的数字，也有停止的规则。不靠感觉判断。

## 现状与目标

| 指标 | 数值 |
|---|---|
| 目前预约 | 约300次/月，每天约10次 |
| 目标 | 600次/月：2月28日前400 · 4月30日前500 · 5月31日前600 |
| 空闲产能 | 约24小时/天（4间房 × 6小时），主要在上午和周一、周二 |
| 诊所每次分成 | 约 $44（$110 的40%） |
| 一个新客户的价值 | 约 $175，按来4次计算，以基线报告为准 |
| 获取一个新客户的成本上限 | **$60**，超过的渠道就暂停 |

**目标人群**：95%的客户用公司保险付费。上午和周一、周二的空档，要留给有保险、那个时间又有空的人：医院倒班人员（Foothills、Children's）、远程和混合办公的人、U of C 的员工和研究生、休产假的父母。没有保险的老年人暂时不作为目标。

## 每月预算（上限 $1,000）

| 项目 | $/月 | 考核标准 |
|---|---|---|
| SEO 外包（60天考察期） | $600 | 从 Google 找到你的客户数 × $175 ≥ $600 |
| Google 广告（诊所周围约8公里） | $300 | 每个新客户成本 ≤ $60 |
| 社区协会通讯广告 | $50–100 | 每次投放 ≥ 1个新客户 |
| 网站聊天机器人（中英双语） | $0–50 | 每月 ≥ 8次可追踪的预约 |
| Instagram / Facebook / TikTok 广告 | $0 | 只做免费发帖，每周1条 |
| 推荐奖励（$15 + $15） | 成功才付 | 每个推荐来的客户成本约 $30 |

## 保留或砍掉的规则

| 项目 | 保留条件 | 否则 |
|---|---|---|
| SEO 外包 | 1月11日前完成第1–4项，并且 Google 带来的客户数 × $175 ≥ $600/月 | 取消，交给 AI 工程师 |
| Google 广告 | 每个新客户成本 ≤ $60 | 暂停，改进落地页后再测一次 |
| 聊天机器人 | 每月 ≥ 8次可追踪预约 | 撤掉 |
| 社区通讯广告 | 连续2期，每期 ≥ 1个新客户 | 停掉该通讯 |
| 工作单位推广 | 每家单位60天内带来 ≥ 5个新客户 | 换下一家 |
| 保险福利活动 | 11–12月 ≥ 75次预约 | 1月换文案和时间 |
| 物理治疗师 | 第2个月起每月 ≥ 40次就诊，且 ≥ 50% 是新客户 | 结束合作 |
| Instagram | 有人在来源里选它 | 减到每月2条 |
| 老年人优惠（暂未启动） | 3月时上午的房间使用率仍低于50%，才测试 | — |
